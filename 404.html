Si vous aviez ajouté SkySpotter à votre écran d'accueil

  1. Ouvrez skyspotter.remibocquet.fr dans votre navigateur.
  2. Réinstallez l'application depuis cette page : menu du navigateur, « Ajouter à l'écran d'accueil ».
  3. Supprimez l'ancienne icône de votre téléphone.

Vous lisez ce message dans l'ancienne application installée : elle ne peut plus se mettre à jour. Le lien ci-dessus s'ouvre dans votre navigateur, c'est de là qu'il faut réinstaller.
